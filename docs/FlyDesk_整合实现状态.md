# FlyDesk 与现有 DeFly 的整合实现状态

最后核验：2026-09-26。工作分支：`codex/flydesk-integration`。

用户选择保留 Cloudflare 架构、3D 果蝇和浏览器大脑。原设计保存在 `docs/design/FlyDesk-v1-product.md` 与 `FlyDesk-v1-technical.md`，架构决定见 ADR-001。本次没有部署或修改线上数据库。

## 已实现的整合

| 模块 | 本分支的实现 |
| --- | --- |
| 版本隔离 | 新 `/api/flydesk` 与独立数据表使用现货规则；旧多空记录和四分类模型保留，不会改标签或自动迁移。共享原有果蝇档案、积分流水和衣柜。 |
| 交易 | BUY/SELL/HOLD，另有 SKIP；不做空；固定最大总扣款 1000；SELL 按快照锁定可卖数量；8 位 BigInt 定点现金、数量、成本、费用；平均成本和系统期末清仓。 |
| 并发与恢复 | 先提交不可变意图，再读取下一根开盘价计算成交；同一步唯一、幂等键冲突检查；未完成意图可从 GET/重试恢复，事务保证只产生一次业务效果。 |
| 历史工作台 | 真实行情或明确标注的本地 fixture；K 线、量能、1m/5m/1h、SMA20/50、RSI14、MACD；指标在服务端计算；部分高周期 K 线标识。 |
| 画线与复盘 | 水平线、趋势线、矩形，锚点移动、删除、撤销重做、缩放和平移；保存数据坐标；动作锁定分析版本；复盘可查看每一步当时行情和画线；JSONL 导出。 |
| 历史数据集 | 管理员导入、分块保存、完整性检查、固定分割边界、按 UTC 指定时点；普通任务不能读取保留测试区间。另有 Coinbase 分页下载脚本。 |
| 账号 | 匿名试用可升级为账号，保留果蝇和物品；Argon2id、随机盐、HttpOnly Cookie、服务端令牌哈希、到期、退出撤销、来源校验、登录限流。 |
| 模型 | 独立三分类 market-only 决策层；真实优化、不可变检查点、个人版本激活/恢复；不接受旧四分类检查点；新回合记录选定版本。 |
| 独立评测 | 使用新定点撮合器及五分钟决策节奏；现金、一档买入持有、全额买入持有、训练前后比较；冻结参数且不接受用户干预。 |
| 浏览器大脑 | 保留全图 WASM 和可视化；教学观察关闭可塑权重更新，观察时长为 500ms；原实验自主模式独立保留。 |
| 实时模式 | Coinbase 公共 ticker/heartbeat 经 Durable Object 接收；服务端时钟、30 秒作答、提交后 250ms 的新报价、5 秒过期、TIMEOUT、断流和缺失估值使回合无效；状态持久化，与历史操作区分开。 |
| 管理及本地运行 | 受 ADMIN_USER_IDS 保护的数据/作业状态和数据导入；一条命令启动本地 UI＋Worker，自动初始化并记录迁移；普通 dev 持久化，fixture 环境独立且不计奖励。 |

## 已执行验证

- 文档第 7.3 节黄金算例全部精确匹配：买后现金 `9000.00000012`，最终现金 `10096.70494420`。
- 10,000 次确定性生成操作：现金、数量、成本和累计费用非负。
- D1 集成：跨账号拒绝访问、重复提交、跨标签竞争、中断后恢复、不可变记录、SKIP 非示范、合成行情不领奖、历史数据集权限及测试区间隔离。
- 从真实交易核心生成的脚本轨迹进入三分类训练服务，生成个人检查点，激活与恢复成功；另一用户不能激活该版本。
- 240 条合成分类样本：确实更新参数，验证准确率不低于 90%，训练损失下降超过 20%。这只验证训练实现，不是市场盈利证据。
- Playwright 使用实际本地 Worker/D1：画线保存、买入、刷新恢复、跳过、完成回合、复盘、账号注册和 HttpOnly Cookie；桌面/手机无横向溢出。
- 实时状态机事件测试：旧价不成交、提交后延迟、新报价、重复请求、无报价过期、超时不是 HOLD、无关产品/乱序拒绝及断流无效。
- Worker 可打包，应用模块语法检查通过。完整测试的最终计数见本文件末尾的本次测试汇总。

浏览器工作台截图使用明确标记的 fixture，并在 UI 测试中主动阻断脑资源加载，故截图中出现真实的脑加载失败提示；该截图不作为神经核运行证据。独立的实际全脑浏览器测试使用真实资源。

## 运行方式

`npm ci`，首次运行再执行 `npx playwright install chromium`。

`npm run dev` 启动真实公共行情模式并持久保存本地数据；访问 `http://127.0.0.1:8876`。`npm run dev:fixture` 是可重复的临时演示环境，所有行情明确标为合成数据。

现有线上数据库只追加 0009、0010、0011 迁移；首次安装由本地脚本初始化。线上还需配置 D1、Durable Object、精确前端来源与管理员 ID，本次没有执行这些部署操作。
