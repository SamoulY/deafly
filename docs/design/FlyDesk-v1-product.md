# 果蝇交易训练场
## 网站功能说明

版本：1.0　｜　日期：2026 年 9 月 14 日　｜　项目暂用名：FlyDesk

## 1. 我们要做什么

这是一个把模拟交易、操作示范和果蝇装扮结合起来的网站。每位用户拥有自己的果蝇，在行情工作台中查看图表、使用指标、画线分析，然后点击“买、卖、不动”。系统模拟成交，保存操作记录，用于训练这个用户的果蝇。

网站可以使用真实的实时行情，也可以回放历史行情；但账户、资金、成交和盈亏始终都是模拟的。用户不能入金、提现，也不会连接交易账户。奖励只有不可兑现、不可转让的虚拟积分，用来兑换外观物品。

**核心体验：看行情 → 做判断 → 获得模拟结果 → 积累带教记录 → 装扮果蝇 → 检查它独立操作的表现。**

## 2. 用户怎样使用

用户注册并领取一只果蝇，进入训练任务。工作台会明确显示资产、时间、模拟现金、持仓、交易额度和本轮规则。用户可以切换图表周期、查看指标、绘制趋势线，再通过三个按钮提交操作。

“买”表示按固定额度增加持仓；“卖”表示减少已有持仓，不代表做空；“不动”表示明确决定保持账户现状。界面另有不显眼的“跳过”，表示没有提交判断，不能算成“不动”的示范。

一个回合结束后，网站显示净盈亏、交易记录、回撤和积分。用户可以回看每次选择，并进入衣柜更换果蝇的服装。积累足够示范后，可启动一次训练，再让果蝇在另一段行情中独立测试。

## 3. 两种行情模式

**历史训练：**指定一个历史时点，图表只能展示截至该时点的信息。用户提交后，行情按任务规则向前推进。切换周期、查看指标或重新加载页面，都不能提前看到未来数据。重复练习可以保留，但不重复领取同一任务的积分。

**实时模拟盘：**使用正在发生的真实行情，所有买卖在站内模拟账户中结算。任务会锁定观察时点和提交窗口；模拟成交使用提交后符合规则的行情，不能按照用户已经看过的旧价格成交。行情断开或过期时，暂停处理并明确提示。

Demo 默认使用一个交易对、固定操作额度和固定回合长度。这些是便于开发和公平比较的初始规则，可以通过配置调整。

## 4. 网站包含哪些模块

| 模块 | 用户看到的功能 | 模块负责的事情 |
| --- | --- | --- |
| 账号与果蝇档案 | 注册、登录、果蝇名称、装扮、训练记录 | 隔离每个用户的账户、示范数据和模型版本 |
| 行情与任务 | 历史训练、实时模拟、资产与时点信息 | 提供可靠行情，限定当时可见的信息，安排训练回合 |
| 分析工作台 | K 线、成交量、周期、均线、RSI、MACD、画线工具 | 帮助用户判断，保存图表设置及画线记录 |
| 模拟交易 | 买、卖、不动，现金、持仓、成交与盈亏 | 按统一规则计算模拟成交、费用和账户变化 |
| 示范记录 | 每次点击、当时的图表与账户状态、后续结果 | 形成能够重放的训练材料，区分用户动作与系统动作 |
| 模型训练与测试 | 数据数量、训练状态、模型版本、独立测试结果 | 执行真实训练，保存检查点，比较训练前后表现 |
| 积分与衣柜 | 回合奖励、积分余额、物品兑换、穿戴预览 | 发放虚拟奖励，保存已拥有物品和当前装扮 |
| 复盘与比较 | 操作时间线、账户曲线、基准结果 | 分开显示用户带教成绩和果蝇自主成绩 |
| 管理与运行状态 | 用户通常只看到维护或故障提示 | 管理数据、任务、奖励规则、训练队列和审计记录 |

## 5. 养成表现是什么

养成主要通过服装、配饰、场景和可验证的历史记录呈现。用户可以兑换帽子、眼镜、领带、背景等，再搭配到自己的果蝇身上。

外观物品不提高交易收益、不改变学习速度，也不修改模型参数。果蝇可以有简单的待机或操作动画，但不需要聊天、情绪值、喂养任务或者“它理解了你的想法”这样的叙述。

界面可以显示“已记录 72 次有效示范”“已完成第 3 次训练”“独立测试尚未显示改善”。这些是实际记录，不是虚构的智力或成长等级。

## 6. 积分如何获得

积分按完整回合结算，净结果需要计入模拟交易费用和期末持仓。符合参与要求、数据完整且净收益为正时，获得少量积分；亏损或持平不发这一轮的盈利积分，但操作记录仍可用于训练。

积分不按点击次数发放，不要求用户频繁交易。“不动”也是有效判断。系统设置单回合和每日奖励上限，同一历史任务不能通过重开账户回合反复领奖。具体额度属于可调整的游戏规则。

积分只能购买明确标价的外观物品，不支持充值、兑现、转赠、玩家交易、抽奖或现金奖品。已经购买的服装不会因一次亏损而消失。

## 7. 怎样判断果蝇真的学到了东西

用户操作时赚了钱，只能说明这轮带教操作表现较好，不能直接记作果蝇的自主能力。网站必须另外提供独立测试：在新行情中，由固定版本的果蝇自行操作，用户不干预，也不在测试过程中更新模型。

每次测试都使用统一的初始条件和模拟成交规则，并展示训练前版本、训练后版本以及简单基准的结果。没有改善时也如实显示，不为了表现养成感而编造进步。

完整 demo 的第一条训练路线是“真实果蝇神经模拟＋用户专属决策层”。首先训练决策层，明确标注学习发生的位置。直接改变果蝇脑内突触的训练属于后续实验，不能把两者混称为同一项成果。实际盈利能力不作承诺。

## 8. 第一版 demo 要交付什么

第一版完成桌面网页中的账号、每人一只果蝇、历史和实时模拟盘、三按钮操作、基本指标和画线、回合结算、积分衣柜、示范记录、个人模型训练及独立测试。模型任务可以排队执行，不能让大脑计算阻塞整个网站。

开发中允许使用明确标注的调试模型和合成行情完成联调，但它们不能代替完整 demo 中的真实行情记录与果蝇模型接入。演示页面要显示当前数据和模型的类型。

第一版不做真钱交易、聊天陪伴、复杂三维身体、杠杆衍生品、果蝇繁殖、玩家物品交易或自动合并所有用户权重。经验共享、更多资产和更复杂的脑内学习可以在基础版本验证后再扩展。

**完成的标准：用户能够完成一轮模拟操作并兑换装扮；后台能够重放该轮记录、执行实际训练、保存版本，并独立检验模型，而不是只展示一组预先写好的结果。**

本文件描述的是拟实现的产品，不代表网站已经建成或模型训练效果已经得到验证。实现范围、接口、默认参数和验收用例见《Codex 技术执行方案》。
